# Custom LineageOS 23.2 development build

Requires a Linux Android build host, repo, git-lfs, Python 3.9+ and upstream Android build dependencies. Plan for 400 GB or more free disk space and 32 GB RAM plus swap (64 GB preferred). Build scripts are not yet validated against a complete source checkout.

From an empty Android source directory:

```bash
repo init -u https://github.com/LineageOS/android.git -b lineage-23.2 --git-lfs
git clone -b dev/lowram https://github.com/RoBroncos/gtowifi_lineageos.git /tmp/gtowifi-custom
python3 /tmp/gtowifi-custom/tools/prepare-custom-manifests.py /tmp/gtowifi-custom/local_manifests .repo/local_manifests
repo sync -j8
device/samsung/gtowifi_mainline/tools/apply-patches.sh
bash device/samsung/gtowifi_mainline/tools/build-local.sh baseline
bash device/samsung/gtowifi_mainline/tools/build-local.sh lowram
```

Keep the pinned manifests generated by the build scripts. The two builds use separate output directories and the same source checkout. Confirm that the experimental build actually contains ro.config.low_ram=true before testing.

Use the upstream README's microSD development instructions only after backing up the device and confirming bootloader and lk2nd compatibility. The script does not flash anything. Images are not OTA packages and are not release-ready.

Follow lowram-testing.md for A/B testing. Do not tune LMKD, CPU governors or ZRAM until the baseline boots and measurements identify a bottleneck.
